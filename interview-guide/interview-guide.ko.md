# 인터뷰 가이드: 6세 조카들과 부모님

2026-10-07 · Daon

English version: [interview-guide.en.md](interview-guide.en.md)

## 알아내야 할 것

이번 인터뷰는 캔버스의 적합성 가설 다섯 가지를 검증하고, 캔버스가 추측만 했던 빈칸을 채우기 위한 것입니다. 부모님은 무엇이 안전하고, 원하고, 현실적인지를 알려 주고, 아이들은 실제로 무엇을 좋아하고 무서워하는지를 보여 줍니다.

| # | 캔버스의 가설 | 누구에게서 | 방법 |
| --- | --- | --- | --- |
| 1 | 밝은 "사라진 조각" 디자인이 어두운 내용에 대한 아이의 두려움을 덜어 준다 | 아이들 | 자극 단계와 관찰, 그리고 부모님이 말하는 아이가 무서워하는 것 |
| 2 | 스스로 설명되는 놀이가 부모의 준비 시간 부족을 덜어 준다 | 부모님 | 평소 미디어와 문화 활동에서의 실제 행동, 그다음 컨셉에 대한 반응 |
| 3 | 놀이에 녹아든 학습이 나중에 기억과 호기심을 만든다 | 아이들, 며칠 뒤 | 회상 확인과 아이가 먼저 꺼내는 질문 |
| 4 | 부모님은 단계별 역사의 양에 만족한다 | 부모님 | 지금까지 해 준 이야기, 해 주고 싶은 이야기, 그 시기 |
| 5 | 조각이 빠진 문은 6세 아이에게 무섭지 않다 | 아이들 | 자극 단계, 불편해 보이는 첫 신호에서 멈춤 |

### 캔버스가 추측만 했던 것

- 아이들이 한국어를 얼마나 이해하고 말하는지, 게임에서 어떤 언어를 써야 하는지.
- 아이들이 이미 아는 것: 장소, 캐릭터, 이야기, 해태.
- 집에서 쓰는 기기와 화면 사용 규칙. VR 기기, PC, 태블릿 중 무엇이 현실적인지 정해 줍니다.
- 부모님이 아이의 한국 정체성을 적극적으로 키우고 싶어 하는지, 그것에 대해 어떻게 느끼는지.
- 이미 쓰고 있는 방법(책, 한글학교, 한국 방문, 영상). 게임이 이것들보다 나아야 합니다.

### 프로토타입 전에 정하려는 컨셉 방향

이번 라운드는 가설을 확인하는 단계라기보다, 프로토타입의 방향을 좁히기 위해 타깃의 생각을 듣는 단계입니다. 아래 다섯 가지 질문에 대한 답이 나오면 충분합니다.

| # | 정하려는 질문 | 현재 선택지 | 확인하는 곳 |
| --- | --- | --- | --- |
| 1 | 어떤 한국 이야기부터 다룰까 | 광화문 복원 이야기 / 온돌·기와·음식 같은 물건으로 만나는 역사 / 둘을 섞기 | 부모 블록 3, 5, 아이 활동 |
| 2 | 아픈 역사를 어떻게, 언제 다룰까 | 게임 안에서 상징적으로 / 게임 밖 대화로만 / 아이가 더 큰 뒤에 | 부모 블록 3 |
| 3 | 아픈 역사를 다문화 환경에서 어떻게 전할까 | 사실 중심 / 평화·이해 중심 / 나중으로 미룸 | 부모 블록 3 |
| 4 | 어떤 형식이 아이에게 맞을까 | VR / 태블릿·PC 화면 / 입체 종이책 / 종이와 디지털 혼합 | 부모 블록 4, 아이 활동 |
| 5 | 아이가 쉽게 받아들이고 재미있어 하는 놀이는 무엇일까 | 퍼즐 / 탐험 / 만들기 / 캐릭터 | 부모 블록 4, 아이 활동 |

앞의 가설 1~5(자극 단계와 회상 확인)는 컨셉을 정한 뒤 두 번째 라운드에서 종이 프로토타입으로 검증해도 됩니다. 이번에 아이 세션의 "사라진 조각" 활동은 선택이고, 아이가 불편해할 만한 자극은 쓰지 않습니다.

## 진행 계획과 순서

부모님을 먼저 인터뷰하세요. 부모님의 답변이 아이들에게 무엇을 어떻게 보여줘도 되는지 정해 주기 때문에, 아이 세션은 그다음에, 회상 확인은 마지막에 합니다.

1. **부모님 인터뷰 (약 60분).** 가능하면 두 분이 함께, 집에서 또는 화상으로 진행합니다. 마지막에 아이 세션에 대한 허락을 구합니다.
2. **아이 세션 (한 명당 10~15분).** 부모님의 조언에 따라 한 명씩 또는 둘이 함께 합니다. 부모님이 방에 함께 있습니다. 놀이를 먼저 하고 컨셉은 그다음입니다.
3. **회상 확인 (3~5분, 3~7일 뒤).** 시험이 아니라 가벼운 안부 대화처럼 합니다.
4. **부모님 후속 질문 (10분).** 그 뒤 아이가 무슨 말이나 행동을 했는지, 집에서 질문을 꺼냈는지 묻습니다.

### 장소

- 아이들 집처럼 익숙한 곳, 잘 쉬고 배부른 시간대.
- 아이 세션 중에는 부모님이 눈에 보이는 곳에 있습니다. 안심한 아이여야 쓸모 있는 반응을 보여 주기 때문입니다.
- 가까운 친척이 진행하면 아이들이 편안해하지만, 어른이 좋아할 만한 대답을 할 위험도 있습니다. 모든 질문을 "나를 도와줄래?" 식으로 하고, 어깨를 으쓱하거나 몸을 비트는 것도 하나의 답으로 기록하세요.

### 역할

- 대화는 진행자가 이끕니다. 필요하면 다른 사람이 메모를 하거나 (동의를 받아) 촬영하게 해서, 진행자는 아이들에게 집중하세요.
- 부모님은 부모님 인터뷰에서는 인터뷰 대상이고, 아이 세션에서는 옆에서 도와 주는 사람입니다. 아이 대신 대답하거나 반응을 유도하지 않도록 미리 부탁하세요.

## 어른과 6세 아이는 어떻게 다른가

6세 아이는 동기를 돌아보거나 아직 없는 제품을 상상하기 어렵습니다. 그래서 아이 세션에서는 행동과 감정을 관찰하고, 부모님 인터뷰에서는 지난 경험과 컨셉에 대한 반응을 묻습니다.

|  | 부모님 | 6세 아이 |
| --- | --- | --- |
| 방법 | 대화, 그다음 짧은 컨셉 설명에 대한 반응 | 놀이, 그림, 사진 고르기, 종이 프로토타입으로 해 보기 |
| 시간 | 약 60분 | 10~15분, 중간에 쉬고 필요하면 일찍 끝냄 |
| 질문 방식 | 실제 지난 일을 묻는 열린 질문 ("가장 최근에 ~했던 때를 말씀해 주세요") | 아주 작고 구체적인 선택 ("어느 게 제일 좋아?")과 보여 주기 과제 |
| 알려 줄 수 있는 것 | 습관, 걱정, 목표, 집에서 현실적인 것 | 무엇을 즐기고 무엇에서 물러서는지, 무엇을 기억하는지 |
| 알려 줄 수 없는 것 | 아이가 그 순간 느끼는 것 | 왜 좋아하거나 무서워하는지, 앞으로 무엇을 원할지 |
| 주된 편향 위험 | 좋은 부모처럼 들리는 대답을 함 | 어른을 기쁘게 하려는 대답, 모든 질문에 "응" |
| 편향 줄이는 법 | 의견이 아니라 행동을 묻고, 유도하는 표현을 피함 | 진짜 선택지 두 개를 주고, 침묵과 몸짓도 답으로 보고, "재미있었어?"를 먼저 묻지 않음 |
| 언어 | 부모님이 가장 편한 언어 | 아이가 고른 언어, 한국어 단어는 놀이의 일부로만 |
| 기록 | 허락을 받은 뒤 녹음이나 메모 | 메모와 관찰, 부모님이 허락하고 아이가 편안할 때만 촬영 |

### 아이를 대할 때의 원칙

- 감정에 대해 "왜"라고 묻지 않습니다. "보여 줘"라고 하거나 두 얼굴, 두 그림 중에서 고르게 합니다.
- 일부러 무서운 자극을 시험하지 않습니다. 목표는 무엇이 무서운지 찾는 것이 아니라, 통하는 것의 가장 순한 쪽을 찾는 것입니다.
- "그만하고 싶어"라고 하거나 자리를 떠나는 것은 분명한 대답으로 받아들입니다.

## 부모님 인터뷰 가이드

이번 인터뷰는 프로토타입을 만들기 전에 컨셉 방향을 정하기 위한 탐색입니다. 한국 정체성 이야기로 시작해 역사, 플랫폼과 게임 방식으로 넘어가고, 컨셉 아이디어는 앞의 답변에 영향을 주지 않도록 끝에 보여 줍니다. 열린 질문을 하고 "조금 더 말씀해 주시겠어요?", "그다음엔 어떻게 됐어요?"로 이어 가세요.

목적 칸의 "방향 1~5"는 앞의 "프로토타입 전에 정하려는 컨셉 방향" 표의 번호이고, "가설 1~5"는 캔버스 적합성 가설의 번호입니다. 부모님의 피로를 생각해 블록 3과 4 사이에 잠깐 쉬는 시간을 두세요.

### 블록 1: 워밍업 (5분)

| 질문 | 목적 |
| --- | --- |
| 아이들과 보내는 보통의 주말은 어떤가요? | 편안한 분위기와 실제 일상 파악 |
| 요즘 아이들이 가장 좋아하는 것은 뭔가요? | 놀이의 단서(캐릭터, 게임, 활동) 찾기 |
| 아이들이 무서워하거나 싫어하는 게 있다면 하나만 얘기해 주세요. | 두려움 주제를 부드럽게 열기 (가설 1) |

### 블록 2: 한국 정체성 (12분) — 가장 먼저, 가장 충분히 얘기하는 블록

| 질문 | 목적 |
| --- | --- |
| 집에서 일상적으로 접하는 한국적인 것에는 어떤 게 있나요? (음식, 언어, 명절, 영상 등) | 현재의 접점과 대안 |
| 아이들은 부모님, 서로, 조부모님과 어떤 언어로 얘기하나요? | 게임 언어와 음성 안내 결정 |
| 아이들이 자기를 소개할 때 한국에 대해 어떻게 말하나요? | 아이가 스스로 느끼는 정체성 |
| 아이들이 한국이나 한국인이라는 것에 대해 마지막으로 물어봤던 때를 얘기해 주세요. | 실제 호기심과 부모님의 대답 방식 |
| 아이들이 한국과 연결된다고 느끼도록 지금 하고 계신 게 있나요? 어떻게 되어 가고 있나요? | 대안: 책, 한글학교, 방문, 영상 |
| 한국 정체성 가운데 아이들에게 꼭 전해 주고 싶은 것을 순서대로 꼽는다면 무엇인가요? (언어, 음식, 명절, 역사, 친척, 가치관 등) | 어떤 이야기부터 다룰지 우선순위 (방향 1) |
| 정체성을 키워 주는 일에서 부담스럽거나 어려운 점이 있나요? 더 도움받고 싶은 부분은요? | 게임이 덜어 줄 불편 찾기 (가설 2) |
| 한국에 대한 책을 아이들과 읽어 본 적이 있나요? 어떤 책이었고 반응은 어땠나요? (그림책, 전래동화, 역사 책 등) | 한국 책 노출 경험과 잘 통하는 형식 |

### 블록 3: 한국 역사 (15분)

| 질문 | 목적 |
| --- | --- |
| 아이들과 한국 역사 이야기를 해 본 적이 있나요? 힘들었던 부분도 포함해서요. 어떻게 말씀하셨고 어땠나요? | 실제 행동과 편안함의 정도 (가설 4) |
| 한국 역사에 관해 아이들이 어떤 교육을 받았으면 좋겠다고 느끼세요? 왜 그렇게 생각하세요? | 교육 목표 (방향 1) |
| 역사를 통해 아이들이 가장 느꼈으면 하는 것은 무엇인가요? (자부심, 배움, 공감, 평화 등) | 전하려는 감정과 톤 |
| 6세 아이에게 어디까지 말해도 되는지 어떻게 정하세요? | 부모님 본인의 기준 파악 |
| 일제강점기나 한국전쟁처럼 어두운 역사를 앞으로 아이들에게 어떻게 다루게 될 것 같으세요? 누가, 언제, 어떤 방식으로요? | 아픈 역사의 방식과 시기 (방향 2) |
| 그런 내용을 게임이 일부 다룬다면, 어떤 방식이면 괜찮고 어떤 방식이면 불편할 것 같으세요? | 게임에서의 경계 (방향 2) |
| 힘든 역사를 설명한다고 상상하면 가장 걱정되는 게 뭔가요? | 겁을 주거나 왜곡할 우려 |
| 아이들 주변에 일본계나 다른 문화 배경의 친구가 있나요? | 다문화 환경 파악 (방향 3) |
| 코리안아메리칸으로서 한국 역사의 아픔을 아이들과 나누고 싶으신가요, 혹은 아직은 나누지 않고 싶으신가요? 그렇게 생각하시는 이유는 무엇인가요? | 아픔을 나누려는 의지와 동기 (방향 3) |
| 다른 문화 배경의 친구들과의 관계에 영향이 갈까 봐 걱정되는 부분이 있나요? 어떻게 대처하세요? | 편견 우려와 대처 방식 (방향 3) |
| 한국 역사와 관련된 책이나 영상을 접한 적이 있나요? 잘 맞았거나 안 맞았던 것은요? | 이미 통하는 것과 아닌 것 |

### 카드로 시기 정하기 (5분, 블록 3에 이어서)

아래 카드를 일직선 위에 놓게 합니다. 시간선은 "6세 전후 / 8~9세 / 10~12세 / 13세 이상 / 아직 모르겠다"로 나눕니다. 카드를 놓을 때마다 "왜 그 시기인가요?"라고 묻고, 말 대신 카드를 옮기는 것도 대답으로 보세요. 부모님이 카드를 추가해도 좋습니다.

| 카드 | 설명 |
| --- | --- |
| 온돌·기와 같은 옛 물건 | 집과 생활 속 물건에 담긴 이야기 |
| 한국 음식 | 떡, 김치 같은 음식에 담긴 이야기 |
| 명절과 풍습 | 설날, 추석 같은 명절의 유래 |
| 궁궐과 왕 이야기 | 광화문 같은 궁궐과 그곳의 이야기 |
| 일제강점기 | 아픈 역사 |
| 한국전쟁 | 아픈 역사 |

### 블록 4: 플랫폼과 게임 방식 (15분)

| 질문 | 목적 |
| --- | --- |
| 요즘 아이들이 가장 재미있게 하는 게임이나 앱, 영상은 무엇인가요? 이름과 좋아하는 이유를 알려 주세요. | 아이들이 재미를 느끼는 요소 (방향 5) |
| 어떤 기기로, 얼마나 자주 하나요? 화면 시간 규칙은 어떻게 되나요? | 기기와 시간의 현실 |
| 혼자 하나요, 같이 하나요? 같이 할 때는 어떤 느낌인가요? | 함께하는 활동의 가능성 |
| 새로운 게임을 처음 만났을 때 아이들은 어떻게 익히나요? (직접 만져 보기, 보고 따라 하기, 설명 듣기) | 조작 난이도와 안내 방식 |
| 화면에서 아이들이 가장 신나서 하는 동작은 뭔가요? (터치, 끌기, 흔들기, 말하기 등) | 인터랙션 아이디어 (방향 5) |
| 아이들이 VR이나 헤드셋 게임을 해 본 적이 있나요? 집에 기기가 있나요? | 경험과 접근성 (방향 4) |
| 해 봤다면 반응이 어땠나요? 안 해 봤다면 어떻게 생각하세요? | VR 수용도 |
| 아이들에게 VR을 접하게 하고 싶으세요? 몇 살쯤이면 괜찮을 것 같으세요? 걱정되는 점이 있나요? (눈 건강, 어지러움, 몰입 때문에 무서울 수 있음 등) | 노출 의사와 우려, 기기 연령 제한 확인 (방향 4) |
| VR이 아니라면 태블릿, PC, TV 중 어디서 하면 가장 자연스러울까요? | 대안 플랫폼 (방향 4) |
| 입체 종이책(팝업북)을 아이들과 본 적이 있나요? 어떤 점을 좋아했나요? | 종이책의 재미 요소 (방향 4) |
| 같은 이야기를 화면(디지털)으로 본다면 아이들이 비슷한 재미를 느낄 것 같으세요? 아쉬울 것 같은 점이 있다면요? (만지는 느낌, 펼치는 재미 등) | 촉각적 재미가 줄어들지 확인 (방향 4) |
| 종이책과 디지털을 함께 쓰는 방식(예: 종이책에 태블릿을 대면 움직이는 그림이 나오는 것)은 어떨 것 같으세요? | 혼합 형식에 대한 의견 (방향 4) |

### 블록 5: 컨셉 아이디어에 대한 반응 (10분)

앞의 블록이 모두 끝난 뒤에만 세 가지 아이디어를 카드로 보여 줍니다. 카드마다 한 문장과 밝은 그림 한 장으로 짧게 준비하세요.

| 카드 | 설명 |
| --- | --- |
| A. 사라진 조각 찾기 | 해태와 함께 광화문의 사라진 조각을 찾아 주는 밝고 짧은 게임. 무서운 장면이 없고, 놀고 나면 부모님이 이야기를 나눌 수 있도록 짧은 안내가 있음 |
| B. 물건으로 만나는 한국 역사 | 온돌, 기와, 음식 같은 물건에 담긴 이야기를 놀이로 만나기 |
| C. 입체 이야기책 | 펼치고 당기면 움직이는 입체 이야기책 (종이 또는 디지털) |

| 질문 | 목적 |
| --- | --- |
| 세 가지를 보고 처음 드는 느낌이 어떠세요? | 묻기 전의 솔직한 첫인상 |
| 지금 아이들에게 하나만 고른다면요? 3년 뒤에는요? 왜요? | 우선순위와 시기 |
| B처럼 물건이나 음식으로 역사를 소개하면, 아이들에게 어떤 물건이 가장 와닿을 것 같으세요? 이미 집에서 접하는 것이 있나요? | 물건 컨셉의 소재 (방향 1) |
| B 방식이 어두운 역사를 피해 가는 것처럼 느껴져서 아쉬우신가요, 아니면 지금 단계에서는 오히려 좋으신가요? | 순한 접근의 수용도 (방향 2) |
| A와 B를 합친다면(예: 기와를 찾아 광화문을 복원하는 것) 어떤가요? | 혼합 아이디어 |
| 아이들이 해도 편하겠다고 생각하시려면 무엇이 필요하세요? 반대로 안 된다고 하실 만한 건 무엇인가요? | 부모에게 필수·기대되는 이득 |
| 어떻게 쓰실 것 같으세요? 아이 혼자, 같이, 손님이 올 때? | 함께하는 활동과 스스로 설명되는 놀이 (가설 2) |
| 부모님용 안내가 있다면 어떤 내용이 있었으면 하세요? | 부모 안내서 설계 |
| 어떤 모습이면 "잘 됐다"고 느끼실 것 같으세요? | 부모 관점의 성공 정의 |

### 블록 6: 마무리 (3분)

- 이야기하면서 새로 떠오른 생각이 있으신가요?
- 제가 묻지 않았지만 꼭 물었어야 할 게 있을까요?
- 아이들과 짧게 놀이 세션을 해 봐도 될까요? 피했으면 하는 게 있을까요?
- 아이들에게 한국 이야기를 해 주는 다른 분(조부모님, 선생님)이 있을까요?

### 피해야 할 표현

- 유도 질문: "~하면 좋을 것 같지 않으세요?", "~가 걱정되세요?" 대신 "~에 대해 걱정되는 게 있다면 무엇인가요?"
- 미래에 대한 가정: "쓰시겠어요?" 대신 지금 하고 있는 걸 묻습니다.
- 지난 선택을 평가하는 말투. 아이들에게 해 주거나 안 해 준 이야기에 대해 중립적인 톤을 유지하세요.

## 아이 세션 가이드

6세 아이에게 이 세션은 인터뷰가 아니라, 볼 것과 할 것이 몇 가지 있는 짧은 놀이 시간입니다. 10~15분을 넘기지 않고, 아이가 이끄는 대로 따라가며, 부모님이 방에 있게 하세요. "내가 만드는 게임인데 도움이 필요해"라고 말하고, 한국에 대한 수업이라고는 하지 마세요.

### 활동 순서

| 단계 | 시간 | 할 일 | 관찰하거나 묻는 것 |
| --- | --- | --- | --- |
| 1. 워밍업 놀이 | 3분 | 아이가 원하는 것을 같이 놀거나 그림을 그립니다. 좋아하는 장난감이나 캐릭터를 보여 달라고 합니다. | 기분, 에너지, 고르는 캐릭터와 게임 |
| 2. 감정 카드 | 1분 | 세 개의 얼굴(기뻐요, 괜찮아요, 무서워요)을 보여 주고 연습합니다. "아이스크림은 어느 얼굴? 큰 소리는?" | 아이가 이해하고 손가락으로 고를 수 있는지, 이후에 이것이 대답 방법이 됩니다 |
| 3. 안내 친구 만나기 | 2분 | 친근한 만화 스타일의 해태 그림을 보여 줍니다. "한국에서 온 친절한 문 지킴이야. 이 친구는 웃긴 것 같아, 용감한 것 같아?" | 첫 반응, 웃는지, 붙여 주는 이름 |
| 4. 다 있는 문 | 2분 | 밝고 온전한 광화문 그림을 보여 줍니다. "서울에 있는 큰 문이야. 이런 문 본 적 있어?" | 아는 것, 호기심, 손가락으로 가리키는 것 |
| 5. 사라진 조각 (종이 프로토타입) | 3분 | 같은 문에서 기와 하나 또는 문 하나가 빠진 그림을 보여 줍니다. 같은 밝은 색입니다. "해태가 조각을 잃어버렸어. 같이 찾아 줄래?" 세 개의 조각 중에서 고르게 합니다. | 몸을 기울이는지, 웃는지, 시도하는지, 걱정하는 기미가 있는지, 글을 읽지 않고 할 수 있는지 |
| 6. 해피엔딩 | 1분 | 문이 다시 온전해집니다. 해태가 스티커나 도장을 줍니다. | 자랑스러움, 부모님께 보여 주려는지, 또 하고 싶어 하는지 |
| 7. 선택과 마무리 | 2분 | "어느 부분이 제일 좋았어?" (그림 두 개로). 감정 얼굴로 "어땠어?"라고 묻고, 고마운 마음을 전하며 스티커를 고르게 합니다. | 먼저 고른 것, 더 하고 싶어 하는지 |

### 컨셉 방향 탐색 활동 (3~5분, 아이가 즐길 때만)

이번 라운드에서는 위 표의 3~6단계(안내 친구와 사라진 조각)를 선택으로 두고, 아래 활동으로 아이가 무엇을 좋아하는지 듣습니다. 각 활동은 그림 카드를 보고 고르는 방식이고, 아이가 지루해하면 그만둡니다.

| 활동 | 방법 | 관찰하는 것 |
| --- | --- | --- |
| 좋아하는 놀이 고르기 | 그림 카드 4장(퍼즐 맞추기, 모험·탐험, 만들기·쌓기, 캐릭터 돌보기·꾸미기)을 보여 주고 "제일 해 보고 싶은 것 한 개만 골라 줘"라고 하고 스티커를 붙이게 합니다. | 먼저 집는 카드, 고민하는지, 왜 골랐는지 일부러 묻지 않고 아이가 절로 말하는 것 (방향 5) |
| 한국 물건·음식 고르기 | 그림 카드 3~4장(따뜻한 온돌 바닥, 지붕 위의 기와, 떡이나 김치 같은 음식)을 보여 주고 "어떤 이야기가 제일 궁금해?"라고 하고 고르게 합니다. | 호기심, 이미 아는 것, "이거 우리 집에 있어"와 같은 연결 (방향 1) |
| 종이책과 화면 비교 | 팝업북이 있으면 아이에게 자유롭게 만져 보게 하고, 이어서 스마트폰이나 태블릿에서 비슷한 움직이는 그림이나 영상을 보여 줍니다. "어느 쪽이 더 재미있어?"라고 묻고 두 그림 중 하나를 고르게 합니다. | 손으로 만지는 정도, 화면에서도 만지려고 하는지, 어느 쪽에 오래 머무는지 (방향 4) |
| 기기 사진 반응 | 태블릿, TV, 헤드셋을 쓴 아이가 나오는 사진 카드를 보여 주고 감정 얼굴로 "이걸 해 보고 싶어?"라고 묻습니다. | 헤드셋 사진에 대한 반응(두려움, 호기심, 무관심) (방향 4) |

### 기기 안전 안내

헤드셋은 기기마다 제조사가 정한 권장 연령이 있고(대개 10세 이상으로 알려져 있으나 기기별로 확인하세요), 6세 아이에게는 눈 건강이나 어지러움 우려도 있습니다. 그래서 인터뷰에서는 아이에게 헤드셋을 쓰게 하지 않고, 사진과 부모님의 이야기로만 확인합니다. 부모님이 집에 기기가 있고 직접 허락하는 경우에만, 그 기기의 연령 안내를 확인한 뒤 아이가 평소 하던 대로 부모님 곁에서 하는 모습을 지켜보는 것까지만 하세요.

### 자극 단계 (단계별로 한 번에 하나씩)

불편해 보이는 첫 신호에서 위 단계로 올라가는 것을 멈추세요. 어둡거나 시끄럽거나 파괴를 보여 주는 것은 사용하지 않습니다.

1. 밝고 온전한 문 (4단계).
2. 같은 문에서 작은 조각 하나가 빠진 모습, 같은 색으로 (5단계).
3. 2단계가 분명히 재미있었을 때만: 두 번째 조각이 빠진 모습, 여전히 밝은 동화책 그림 스타일.

어느 단계에서든 불편한 기색이 보이면 온전한 문과 해피엔딩으로 돌아가고, 어느 단계에서 일어났는지 기록하세요. 이것이 가설 1과 5에 대한 답이 됩니다.

### 언어

아이가 대답하는 언어를 쓰세요. 한국어 단어("해태", "광화문")는 단어 시험 없이 놀이의 일부로만 쓰세요.

### 회상 확인 (3~7일 뒤)

미리 알리지 마세요. 평소의 방문 중에 가벼운 이야기로 꺼내세요. 스티커를 가지고 놀거나 "우리 문 게임 기억나?"라고 묻습니다. 무엇을 묻기 전에 아이가 먼저 꺼내는 이야기를 기록합니다.

| 질문 또는 행동 | 무엇을 보여 주나 |
| --- | --- |
| 게임 얘기를 하지 않고 아이가 직접 꺼내는지 본다 | 자발적인 기억과 호기심 |
| "문을 지키던 친구 누구였지?" | 캐릭터 기억 (가설 3) |
| "그 친구가 무엇을 도와 달라고 했었지?" | 과제 기억 (가설 3) |
| "또 하고 싶어?" | 예의가 아닌 진짜 관심, 얼마나 신나하는지 보기 |

## 제3자 인터뷰 가이드 (한국인·교포 2세·일반 성인)

부모님과 아이가 아닌 외부의 시선을 듣는 인터뷰입니다. 두 가지를 중점으로 묻습니다. 첫째, 6세 아이에게 한국 역사를 다루는 일을 사회적으로 어떻게 보는가. 둘째, 같은 소재(일제강점기, 한국전쟁)를 일반 성인을 위한 게임으로 해석하면 어떤 재미와 의미가 가능하고, 어디에서 선을 넘는가. 기기와 게임 매체 질문은 부모님·아이 인터뷰와 같은 틀로 묻고 나중에 비교합니다.

### 알아보려는 것

| # | 알아보려는 질문 | 확인하는 곳 |
| --- | --- | --- |
| 1 | 6세 아이에게 한국 역사를 다루는 것을 어떻게 보나 (필요성, 시기, 방식) | 블록 2, 카드 정하기 |
| 2 | 아이에게 어두운 역사를 다룰 때 무엇이 괜찮고 무엇이 불편한가 | 블록 2 |
| 3 | 일반 성인에게 일제강점기·한국전쟁을 게임으로 풀면 어떤 재미와 의미가 가능한가 | 블록 3 |
| 4 | 어느 지점에서 선을 넘는다고 느낄까 | 블록 3 |
| 5 | 어떤 기기와 게임 매체가 자연스럽고 어른용으로 확장할 수 있는가 | 블록 4, 5 |

### 누구에게 물을까

처음에는 각 집단에서 2~3명으로 시작해도 충분합니다. 모두 만 18세 이상의 성인이고, 아이가 있어도 되지만 부모님 인터뷰에 나온 분들은 제외합니다.

| 집단 | 필요한 이유 | 유의할 점 |
| --- | --- | --- |
| 한국에서 나고 자라 한국인 성인 (한국 또는 미국 거주) | 한국식 역사 교육을 받은 시선, 6세에게 무엇을 어떻게 가르치는지에 대한 기준 | 한국 교육 방식을 기준으로 삼아 해외 환경의 사정을 놓칠 수 있음 |
| 교포 2세(코리안아메리칸 성인) | 조카들과 같은 환경을 지나온 사람, 어릴 때 무엇이 도움이자 부담이었는지 | 기억이 미화되거나 지금의 감정이 섞일 수 있음 |
| 일반 성인 게이머 (한국인이 아니어도 됨, 한국 역사에 대한 지식 정도는 다양) | 게임으로서의 매력과 이해도, 어른용으로 확장할 가능성 | 일본 등 당사자성이 걸리는 참가자는 동의를 받고, 편한 선에서만 이야기하게 함 |

참가자를 고를 때는 다음 세 가지만 간단히 확인합니다: 어느 집단에 해당하는지, 6세 전후 아이를 돌본 경험이 있는지, 평소 게임을 어느 정도 하는지.

### 진행 방식

- 한 명씩, 약 40~45분, 대면 또는 화상. 부모님 인터뷰 전후 언제 해도 되지만, 부모님 답변이 참가자에게 전해지지 않게 합니다.
- 녹음이나 메모 전에 동의를 받습니다. 가족사나 개인적인 경험이 나올 수 있는 주제임을 미리 알리고, 어떤 질문이든 건너뛸 수 있다고 말씁드립니다.
- 어른은 "올바른 답"을 말하려는 경향이 있습니다. 정답이 없다고 알리고, 의견보다 경험과 행동을 묻습니다.
- 진행자의 입장이나 판단은 말하지 않고, 역사적 쟁점이나 정치적 논쟁으로 이끌지 않습니다.

### 피해야 할 표현과 유의사항

- 진행자가 한국인이라는 이유로 한쪽 입장에 동의하도록 유도하지 않습니다. "일본이 잊못했죠?"같은 질문 대신 "이 소재에 대해 어떤 시선이 있나요?"라고 묻습니다.
- 판단하는 말투를 피합니다. "그런 게임은 불편하지 않아요?"라는 질문 대신 "어떤 부분이 편하시고 어떤 부분이 불편하신가요?"라고 묻습니다.
- 가족사나 피해 경험이 나온다면 질문을 멈추고 잠시 듣는 시간을 가집니다. 이야기를 더 묻지 않고, 원하면 건너뛰거나 멈출 수 있다고 다시 말씁드립니다.
- 역사적 사실에 대한 논쟁이 시작되면 사실 관계를 따지지 말고 "게임의 관점에서는 어떤가요?"라고 묻며 되돌립니다.

### 부모님에게

- 목적을 두 문장으로 설명하고, 무엇을 기록할지(메모, 녹음, 사진)와 어디에 쓰일지(예: 수업 프로젝트, 포트폴리오)를 말씀드립니다.
- 녹음이나 촬영 전에, 그리고 아이들의 이름, 사진, 그림을 쓰기 전에 분명한 동의를 받습니다. 이름은 이름만, 또는 밝히지 않는 방법을 제안합니다.
- 어떤 질문이든 건너뛸 수 있고 언제든 멈출 수 있으며, 아이를 키우는 방식에 정답이 없다는 것을 말씀드립니다.
- 아이 세션 전에 무엇을 보여도 되고 무엇은 안 되는지 합의합니다.

### 아이들에게

- 쉬운 말로 같이 게임을 해 볼지 묻습니다. 아니라고 하거나 자리를 떠나면 설득하지 않고 멈춥니다.
- 부모님이 방에 있게 하고, 아이가 원하면 옆에 앉게 합니다.
- 아이가 인상을 쓰거나, 조용해지거나, 그만하고 싶다고 하거나, 숨거나, 부모님을 자꾸 바라보면 즉시 멈추고 해피엔딩으로 넘어갑니다.
- 아이가 물러선 것에 다가가거나 만지게 하지 않습니다.
- 일찍 멈추더라도 모든 세션은 온전한 그림과 스티커로 마무리합니다.

### 자료와 그림

- 메모와 녹음은 비공개로 하고, 필요한 내용을 정리한 뒤 녹음은 삭제합니다.
- 아이들의 그림은 돌려주거나 보관하기 전에 허락을 받습니다.
- 특정 아이에 대한 관찰은 부모님의 허락 없이 가족 밖에서 공유하지 않습니다.

### 이번 라운드에 추가로 준비할 것

- **부모님용 카드:** 컨셉 카드 3장(A, B, C), 시기 정하기 카드 6장과 시간선 종이. 일제강점기와 한국전쟁 카드는 글자만 쓰고, 아이들에게는 보여 주지 않습니다.
- **아이용 카드:** 좋아하는 놀이 4장, 한국 물건·음식 3~4장(온돌 바닥, 기와, 떡, 김치 등), 기기 사진 카드, 감정 얼굴 카드.
- **종이책과 화면 비교용:** 집에 있거나 도서관에서 빌린 팝업북 1권과, 비슷한 느낌의 움직이는 그림 또는 영상 1개.
- **스티커:** 고르기 활동에서 쓰는 스티커와 마지막 보상용 스티커.
- **모든 그림은** 밝고 친근한 스타일로 하고, 어두운 장면이나 파괴를 연상하는 이미지는 쓰지 않습니다.

## 별도 프로젝트 메모: 입체 종이책의 디지털 버전

이 메모는 이번 게임 프로젝트와 별개로 진행할 아이디어입니다. 인터뷰의 블록 4와 종이책·화면 비교 활동이 출발점이 됩니다. 핵심 질문은 "화면으로 옮기면 줄어드는 촉각적 재미를 인터랙션으로 어떻게 보완할까?"입니다. 디지털 스토리텔링이 가능하다는 장점은 살리되, 아래는 모두 가설입니다.

### 입체 종이책이 재미있는 이유 (확인할 가설)

- 펼치는 순간의 놀라움.
- 직접 당기고, 들추고, 접는 손의 움직임과 그에 따른 즉각적인 반응.
- 입체감과 깊이: 겹겹이 쌓인 층.
- 종이 소리와 촉감.
- 어른과 함께 넘기며 나누는 시간.

### 디지털로 옮길 때의 인터랙션 아이디어

| 종이책의 재미 | 디지털에서의 아이디어 | 주의할 점 |
| --- | --- | --- |
| 탭(손잡이) 당기기 | 손가락으로 끌면 고무줄처럼 늘어났다 돌아오고, 끝까지 당기면 튀어나옴 | 아이가 끌기 동작을 쉽게 하는지 확인 |
| 덮개(플랩) 열기 | 살짝 들추면 아래가 보이고 놓으면 다시 닫히며 소리가 남 | 덮개를 못 열어도 진행할 수 있게 함 |
| 펼치면 솟아오르는 입체 | 페이지를 넘길 때 층이 순서대로 일어나는 애니메이션, 기기를 기울이면 층이 어긋나 보이는 시차 효과 | 어지러움이 없도록 약하게 |
| 종이 소리와 촉감 | 종이 넘기는 소리, 접는 소리 같은 효과음과, 지원되는 기기에서는 가벼운 진동 | 소리 크기 조절을 제공 |
| 함께 읽기 | 부모님이 글을 읽고 아이는 그림을 만지는 역할 나눔, 두 사람이 한 화면에서 손을 쓸 수 있는 큰 터치 영역 | 어른의 등장이 아이의 조작을 막지 않도록 |
| 숨은 것 찾기 | 페이지마다 숨은 그림 하나, 눌러 보면 반응하는 작은 장난 | 못 찾아도 진행에 문제가 없게 함 |
| 종이와 디지털 혼합 | 실물 입체책에 폰이나 태블릿을 대면 소리와 움직임이 더해짐 (AR이나 QR·NFC로 소리 재생) | 만드는 비용과 난이도가 커서, 초기에는 종이와 영상 목업으로 확인 |

### 한국 소재와 연결하는 예

- **온돌:** 아궁이에 불을 때면 바닥이 따뜻해지는 빛이 퍼지는 장면. 불씨를 모으는 끌기 동작과 따뜻한 소리로 표현합니다.
- **기와:** 지붕 위에 기와를 한 장씩 올리며 입체 지붕이 완성되는 장면.
- **광화문:** 페이지를 펼치면 문이 열리고 해태가 튀어나오는 장면.

### 먼저 확인할 작은 실험

- 종이책과 화면 비교 활동에서 아이가 어떤 동작에 반응하는지 관찰하고 기록합니다.
- 같은 장면을 종이 컷아웃과 화면 애니메이션으로 만들어 비교합니다. 비용이 적게 드는 목업으로 충분합니다.
- 어른과 아이의 손이 함께 쓰이는지 확인합니다.
